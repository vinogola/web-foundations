About QuickNotes

QuickNotes is a simple place to capture ideas, reminders, and thoughts whenever inspiration strikes. It helps you keep track of important moments, plans, and creative sparks in one easy place.

How to use QuickNotes

  1. Open QuickNotes and start a new note.
  2. Write down your idea, reminder, or thought.
  3. Save your note so you can find it later.

Features

  • Capture ideas quickly
  • Save reminders and thoughts
  • Find notes whenever you need them

Keyboard shortcuts

Shortcut Action
Ctrl + N Start a new note
Ctrl + S Save your current note
Ctrl + F Search for an existing note
